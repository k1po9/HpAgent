# 人工 E2E 四项问题：实施与验收

日期：2026-10-04（Asia/Shanghai）。对应 [调查方案](./manual-e2e-investigation.md)。实现基于工作目录现有改动继续完成；没有修改迁移历史、覆盖旧模型快照，也没有给旧文件自动补授其他对话的权限。

## 已实施

### 目录新建和 409

- 新建目录使用独立空名称，父目录默认是所选目录；选中文件时使用其父目录。新建成功选中新目录，刷新保留有效选择。
- 改名/移动仍编辑原节点，与新建分开。页面显示当前完整路径。
- 已知数据库约束按 `name_exists`、`invalid_name`、`invalid_parent`、`directory_not_empty` 等返回 `details.reason`，界面显示明确原因和请求编号；未知数据库异常保持内部错误。

### 长期文件的下一轮发现

- 上传用途可选择“上传并供当前对话使用”或“仅保存”。有当前对话时默认授予新文件的发现和读取权限；无当前对话时只保存。
- 保存成功但授权失败时保留文件，支持“补授权”，不重复上传。授权查询和后端去重均避免重复规则。
- Chat 初始上下文加入授权候选数量、第一页最多 20 条元数据和分页指引；Work brief 同样检查当前授权，并包含已绑定输入的逻辑名。
- 清单为空时引导在资料授权页授权已有文件，避免要求重新上传；环境提示区分长期文件、Run 文件、可选 Git 代码目录。
- 当前 Run 的候选继续冻结，运行中新增文件/权限下一次执行生效。未授权对话不注入其他文件名；撤销和执行租约继续检查。

### 工具往返失败和诊断

- Provider serializer 更新为 `hpagent-provider-request-v2`，统一转换内部 transcript、OpenAI 和 Anthropic 工具调用/结果；OpenAI 输出嵌套 `function` 与 JSON 字符串参数。
- 校验孤立/重复结果、重复调用 ID、缺少结果、非法参数。普通 user 消息不猜测为工具结果。本地格式错误在快照冻结、额度预留和 HTTP 分发前拒绝。
- 分开记录请求格式、响应解析、HTTP、连接、读取超时、权限和额度问题；日志保留 HTTP 状态、受限的 Provider code/request ID 和 Run/调用/快照/阶段/尝试关联，不记录 Provider 自由文本错误消息。
- 新错误类别贯通 Activity、生命周期最终错误名单、Run DTO 和重试命令。不可重试模型错误不会被展示成“外部操作结果不确定”。
- 重载验收发现错误分类模块的顶层 HTTP 依赖会被文档工作流沙箱间接导入，导致 Worker 校验失败；已改为仅在 Activity 分类调用时加载。增加全部 8 个注册工作流的沙箱校验，并在当前 Worker 容器中逐个验证通过。
- Artifact 单独使用默认 90 秒读取预算，可配置 `ARTIFACT_MODEL_READ_TIMEOUT_SECONDS`（5–300 秒）；连接等待最多 5 秒，聊天原读取预算保持配置值。测试同时验证 Anthropic 的 system 字段仍计入预算。

### 人工操作页面

导航分为 **对话、长期文件、资料授权、持续工作、研究、成果、执行诊断、账户**，采用轻量 hash，不增加路由库。

- 对话保留消息、附件、取消/重试、策略和资料提示；切页保留草稿与订阅。`succeeded` 后策略解锁并正确显示新选择。
- 长期文件提供目录、上传、搜索、版本与编辑；移除面板的高度上限。
- 资料授权分别选择对话或工作，提供发现/读取/保存/更新/删除权限、递归规则、工作输入和撤销。
- 工作和研究可直接创建合法 Requirement；工作支持修订、时间、约束、控制、额度、结果确认与收件箱。修订使用加载时版本并仅发送可编辑字段，保留资源要求、交付策略、原验收条件与来源策略。
- 成果提供消息来源、版本、交互预览、HTML 下载和长期保存；HTML 源码按允许的文本文件上传，交互预览保留在成果页。
- 消息、研究输出和成果的保存有独立目录选择对话框，不依赖文件页挂载状态；不确定响应重用命令身份。
- 诊断可选择对话/工作 Run，查看 Trace、模型快照与分类错误；基本操作无需手填 UUID，高级查询仍可输入编号。

## 建议复测路径

1. 长期文件 → 选中资料 → 输入新目录名称 → 新建；同级重名应显示具体冲突。
2. 选择当前对话 → 上传并供当前对话使用 → 回到对话询问文件内容；若只保存或是旧资料，在资料授权页先授予发现/读取。
3. 持续工作 → 创建指定时间提醒 → 选择该工作修订 → 在资料授权页授予工作目录权限；研究页直接创建研究并查看执行/报告。
4. 从已完成回复生成成果 → 下载或选择目录保存源码；执行诊断页查看失败分类、模型请求快照和尝试次数。
