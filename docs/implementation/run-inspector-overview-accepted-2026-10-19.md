## 比例时间轴的真实语义

时间点位置为 `(事件时刻 - 创建时刻) / (结束或当前采样时刻 - 创建时刻)`。等待区间用银灰，执行区间用焰橙细线，成功终点为语义绿；失败用原错误色，取消用中性色。颜色区分阶段和结果，不把橙色当作成功或百分比进度。

- 创建与开始相同时合并“创建 / 开始”；所有时间相同则只有一个节点、无区间线。零等待不虚构最小宽度。
- 节点较近时，点的位置不挪动；根据可用宽度把标签错到下一行，避免文字交叠。ResizeObserver 随拖宽重新排标签，不重新加载 Run，不挪动真实比例。
- 同日仅在顶部显示一次日期；跨日的各事件补日期，完整本地时间仍在 time/title 中。耗时按实际时间差；运行中标“截至”当前采样时间，不伪造完成时间或预计总进度。
- 未开始的真实 queued 只画到当前时刻的等待段，保留“尚未开始”。时间缺失/无效/倒序时展示已有记录与说明，不绘制虚假比例。未知不等于零。
- 沿用可见时每秒更新耗时、隐藏时跳过、终态清理定时器；完成图形和历史时间轴静止，原活跃信号/减动机制保持。
