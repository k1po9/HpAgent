# Workspace v4.1 实施与验收

本目录记录 P0～P5 的实际修改、隔离验证及剩余运行验收。阶段记录反映各阶段当时状态；跨阶段最终状态以[总体验收](ACCEPTANCE.md)为准。当前系统契约见[架构说明](../../architecture/workspace-v4.1.md)。

| 阶段 | 记录 | 主题 |
| --- | --- | --- |
| P0 | [实施记录](P0.md) | Account 所有权、独立 Run 输出与跨对话输入 |
| P1 | [实施记录](P1.md) | 长期目录/入口、零复制保存与统一 GC |
| P2 | [实施记录](P2.md) | 授权、Run 候选快照、固定版本与撤销 |
| P3 | [实施记录](P3.md) | Destination 修订、CAS 与历史幂等 |
| P4 | [实施记录](P4.md) | Research 固定历史与 Task 自动保存 |
| P5 | [实施记录](P5.md) | 检索、保留/空间可见性与规模测量 |

[总体验收](ACCEPTANCE.md)顶部是当前 I01～I19 状态的权威入口，分别列出源码实现、本地运行和远端 CI 证据；其下保留各次验收的当时记录。阶段实施结束不等于所有运行场景均已确认完成。

后续 Durable Work 将持续委托与权限主体统一为 Work；本目录 Task 描述保留阶段历史。当前 [Workspace 契约](../../architecture/workspace-v4.1.md)及[跨阶段实施索引](../README.md)连接五阶段重建、复查和人工 E2E 修复。
