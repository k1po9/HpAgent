## 调整

- 轨迹使用浅银瓷渐变大容器、轻边界与柔和阴影，标题和刷新一层；宽面板将真实状态、节点数、总跨度移至标题右侧，窄面板自然换行。
- 根节点使用暖橙渐变、橙色边缘和轻光晕；主线从根部暖色渐变为银灰，用定位材质表达根关系，不当作执行进度。成功图标仍用语义绿，采用参考的圆形绿勾。
- 普通节点增大行高和字号，以细分隔、连续主线和低强调连接点组织阅读；耗时统一右对齐。复合子树的子节点集中在一层银瓷内嵌面，父行保持开放。
- 深层树收敛缩进，并显示真实层数，避免窄屏只剩耗时；选中节点的详情仍显示完整名称。模型输入标记仅在节点确实带 snapshot_id 时出现；按原入口查看，不新增常驻分区或请求。
- 节点详情外观统一为银瓷材质，内容、容器和权限逻辑保持。上轮身份和用量组件、预算口径及后端代码无修改。

只改 Run 高级页的表现层和相应用例截图路径。名称选择与展开按钮仍分离，刷新和拖宽保留选择／展开；动效仍由真实 running 状态驱动，成功静止，减动立即停下。
