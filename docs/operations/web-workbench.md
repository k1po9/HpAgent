# 功能操作与人工校验

前端只有 AI、空间、任务三个一级入口。登录位于业务 Shell 之前；账户与 QQ 绑定从头像打开。Run、文件、Task 和 HTML Artifact 在当前页面的 Inspector 中查看；面板内部返回可回到父对象。切页保留对话草稿，退出和账户切换清空账户内状态。本指南已同步 UI-1～UI-8 重构（2026-10-09）；架构契约见[Web 前端](../architecture/web-ui.md)，验证与未覆盖环境见[重构交接](../implementation/ui-refactor.md)。

| 入口 | 主要操作 |
| --- | --- |
| AI：`#/ai`、`#/ai/{conversationId}` | 对话、历史分页、附件、快速/深度策略、取消/重试；Header 管理资料、生成 HTML、按编号核实 Run。消息行查看执行与 HTML。 |
| 空间：`#/workspace?dir={nodeId}` | 目录、上传、搜索、文件 Inspector、版本、改名/移动、保留空间与来源；为明确选中的对话或任务管理权限。 |
| 任务：`#/tasks?bucket=attention&type=all` | 四桶筛选；创建/修订提醒、研究或通用工作；计划、预算、投递、成果验收、使用资料与局部收件箱。`work={workId}` 打开指定任务。 |
| 上下文 Inspector：`inspect=run:{id}`、`file:{id}`、`artifact:{id}` | 执行详情与高级诊断、文件内容与版本、HTML 预览/版本/修改/下载/保存；打开对象仍须服务器验证权限。 |
| 头像 → 账户设置 | 账户资料、QQ 绑定和退出；QQ 引导可跳过。 |

旧 `#chat`、`#files`、`#works`、`#research` 地址兼容迁移到三个入口。旧 `#artifacts` / `#diagnostics` 没有明确对象时回到 AI；`#account` 打开账户设置。URL 只携带对象标识与布局枚举。

## 新建目录与长期资料

在空间的目录树选中“资料”或其他目录，再新建目录；父目录就是当前目录。文件行打开 File Inspector，从其中改名/移动、查看版本或来源。同级重名会显示具体冲突原因和请求编号。移除是删除空间入口，当前没有回收站恢复能力。

空间上传显式选择保存与授权目标；仅保存只创建长期入口。保存成功但授权失败会保留已上传文件，补授权不需要重新上传。支持当前服务端白名单内的文本、PDF、DOCX、XLSX、PPTX，不承诺图片或任意 FIG 文件。

已有文件在 AI Header 的资料管理、Task Inspector 的使用资料，或 File Inspector 的 AI 使用范围中，选择明确主体与目录/文件后授权。所有者看到文件不等于 Agent 已获权限；关联对话也不自动授权 Work。目录递归授权覆盖当前允许的范围，新 Run 冻结候选；运行中上传或新增权限不扩展该 Run，下一轮执行生效。撤销仍会阻断已冻结资源的后续受控访问。文件历史使用记录与当前主体授权分别显示，当前没有全账户有效主体反查。

## 持续工作与研究

在任务 Header 新建提醒、研究或通用任务。计划仅支持立即、指定时间和每天，填写时区；每日任务为 ongoing。通知入队、渠道接受与任务完成分别展示。通用工作支持 ReAct / Plan-and-Execute；内部 HTML 生成任务也出现在通用类型中。

任务按需要我处理、进行中、等待或已计划、已结束分类。单次 Run 成功不会将持续任务判为完成；正在暂停/停止的任务可能仍有投递待决。列表未完成全部分页时显示已加载范围，不能用局部计数判断全账户无待办。

选中任务后在 Inspector 修订要求，提交时检查加载的 Work 版本；出现冲突保留草稿，刷新后重新核对。取消一个 Run 保留 Work 委托，停止 Work 是另一项控制。提高累计预算是显式命令，重试和修订不会清零已使用额度。使用资料 Tab 管理 Work 权限和 ready/input 文件引用。

研究类型创建的是 `research_report` Work，运行固定研究图；Task Inspector 的成果与执行展示报告、证据和保存情况。required 保存未成功时不能以报告已经生成代替完成。成果接受与渠道回执分开；uncertain 投递先核对真实渠道，再对具体投递作显式决议。“确认未发送”可能重新尝试发送；重复风险重试需单独确认；渠道 accepted 不代表用户已读。通用外部未决 operation 只提供核查与诊断，当前无通用人工对账命令。

## 成果和保存

选择已完成且有正文的 assistant 回复生成 HTML，或使用 AI Header 的生成入口，版本和生产 Run 保持可追溯。HTML 在当前页面 Inspector 中预览、查看历史和修改；修改基于最近成功版本，历史版本不可任意分支。下载 `.html` 保留交互；保存到空间使用 `成果-vN.html.txt` 文本源码副本，交互预览仍在 Artifact Inspector。

打开 Task 成果时保留原交付版本。手工修改生成的新 HTML 版本不会自动成为原 Task 的验收交付物；接受按钮只绑定当前 revision 的有效交付证据。保存、授权和接受是各自明确的用户操作。

消息、研究输出与 HTML 使用局部目录选择对话框，不必先打开空间。生成成果、发布文件和保存长期入口是不同操作；保存失败不代表生成内容丢失。上传已 ready 而保存失败时继续原保存，不重新上传；同名冲突可改名后继续。

## 执行诊断

从消息执行块或 Task 的某次执行打开 Run Inspector；AI Header 与 Task 高级详情也可输入已有编号。先查看失败 code / message / retryable，再切到高级诊断查看 Trace、Model Input 和日志。历史 Run 不被当前聊天流抢占；Model Input 仍受账户可见范围限制。诊断没有独立一级入口。

文件与页面验收可使用[浏览器回归](../development/testing.md)。这些测试由真实 API / PostgreSQL / Redis 与测试执行器组成；真实模型、QQ 和生产恢复验收要另行执行。已知边界及证据见[实施索引](../implementation/README.md)。
