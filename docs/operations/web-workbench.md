# 功能操作与人工校验

前端采用八个 hash 页面，选择的当前 Conversation 在页面间共享。切页保留对话草稿，账户切换会重建账户内状态。此指南对应 `0fcf505`。

| 页面 | 主要操作 |
| --- | --- |
| 对话 | Conversation、消息、附件、策略、取消/重试和资料提示。 |
| 长期文件 | 目录、上传、搜索、版本、改名/移动、保留空间和来源。 |
| 资料授权 | 给当前对话或指定 Work 授权，管理 Work 输入引用、递归范围和撤销。 |
| 持续工作 | 创建/修订提醒或通用工作，时间/约束、暂停/恢复/停止/推进、预算、成果验收及收件箱。 |
| 研究 | 创建研究 Work，查看执行、来源、证据和报告。 |
| 成果 | 从已完成回复生成、改版、预览、HTML 下载和长期保存。 |
| 执行诊断 | 选择聊天或 Work Run，查看状态、失败原因、Trace 和模型请求快照。 |
| 账户 | 账户资料、QQ 绑定和退出。 |

## 新建目录与长期资料

在长期文件页选中“资料”或其他目录，输入独立的新目录名称后新建；父目录就是选中目录。选中文件时以其父目录新建。改名/移动使用原条目的编辑区。同级重名会显示具体冲突原因和请求编号。

有当前对话时，上传默认选择“上传并供当前对话使用”：保存文件后授予该文件的发现和读取权限。选择“仅保存”只创建长期入口。保存成功但授权失败会保留已上传文件，点击补授权即可，不需要重新上传。

旧文件、只保存的文件或 Work 所需资料，在资料授权页选择主体与目录/文件，勾选发现、读取等操作后授权。所有者看到文件不等于 Agent 已获权限；关联对话也不自动授权 Work。目录递归授权覆盖当前允许的范围，新 Run 冻结候选；运行中上传或新增权限不扩展该 Run，下一轮执行生效。撤销仍会阻断已冻结资源的后续受控访问。

## 持续工作与研究

直接在持续工作页填写标题、目标、能力、约束和时间。一次提醒使用带时区的时间，每日提醒使用指定时区且为 ongoing；通知入队、渠道接受与委托完成分别展示。通用工作支持 ReAct / Plan-and-Execute。

选中工作后修订需求，提交时检查加载的 Work 版本；出现冲突先刷新并核对新状态。取消一个 Run 保留 Work 委托，停止 Work 是另一项控制。增加累计预算是显式命令，重试和需求修订不会清零已使用额度。工作需要资料时到资料授权页选择该 Work，添加资源权限或文件输入。

研究页创建的是 `research_report` Work，运行固定研究图；页面展示报告、证据和保存情况。required 保存未成功时不能以报告已经生成代替完成。工作结果确认与渠道回执分开；uncertain 投递先核对真实渠道，再作显式决议。

## 成果和保存

选择已完成的 assistant 回复生成成果，版本和生产 Run 保持可追溯。打开 Work 成果时查看引用的精确版本。下载 HTML 可以保留交互页面；长期保存当前使用 `成果-vN.html.txt` 文本源码，交互预览仍在成果页。

消息、研究输出与成果使用独立的目录选择对话框，不必先打开文件页。生成成果、发布文件和保存长期入口是不同操作；保存失败不代表生成内容丢失。

## 执行诊断

通过当前对话或 Work 选择 Run，无需手填 UUID；高级输入仍可用于已有编号。先查看失败 code / message / retryable，再查看 Trace、模型快照和日志。模型输入可见范围仍受 Account entitlement 限制，页面入口不提升权限。

文件与页面验收可使用[浏览器回归](../development/testing.md)。这些测试由真实 API / PostgreSQL / Redis 与测试执行器组成；真实模型、QQ 和生产恢复验收要另行执行。已知边界及证据见[实施索引](../implementation/README.md)。
