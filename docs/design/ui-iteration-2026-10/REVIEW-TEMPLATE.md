## HANDOFF.md

### 一句话状态

R? / attempt-??：实施中 / 自审未通过 / 待人审 / 人审返修 / 已接受 / 环境阻塞。

### 总调度必须知道

1. 基线与当前 HEAD、分支、工作区绝对路径，是否已提交；未提交 diff 指纹。
2. 变更文件与每组变化目的；用户原有未提交改动是否保持。
3. 实际实现的内容、明确没有实现的内容、与原计划差异。
4. 默认页面表现；候选预览 URL/启动步骤；所需服务、端口、数据；停止服务/关闭候选/回退方法。
5. 核心截图索引、SELF-REVIEW、VALIDATION 的链接。
6. 技术验证结果、未关闭问题及影响；已停止/仍在运行的本轮服务。
7. 代理推荐与取舍；用户已作出的明确决定，或“尚待用户选择”。
8. 下一轮可依赖的稳定接口/样式/Token；不能假定完成的部分。
9. 给总调度的待决项，不自动扩展为下一轮任务。
