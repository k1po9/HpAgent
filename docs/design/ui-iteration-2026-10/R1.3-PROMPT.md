## 4. 最终自审与验证

完成一次横向一致性检查：Header、Rail/Context、正文、对象卡、Composer、Inspector、Surface在字号、间距、圆角、边界、操作主次上是否形成一致规则；Workspace/Tasks/登录受共享样式影响时不退化。提炼实际采用的规则和适用例外，不为文档创造未实现的设计系统。

- 1680、1280、780、390宽度及1279/1280边界，桌面/手机短屏。
- 空态、短答、长中英文、列表/引用/表格/代码、多轮多对象、长文件名。
- idle/focus/disabled、上传中/失败、真实queued/running/failed及退化提示，保持当前事实映射。

- 对比度、触摸目标、横向溢出、错误状态及主要操作可见性。
