# R5.0 交互合同 · 已接受

日期 2026-10-16。用户“通过，下一步任务是什么，先给出你的方案”明确接受 R5.0；本合同按本窗口八条建议形成，现已接受。最新决定见 [R5.0 接受决定](../../../artifacts/product-acceptance/ui-iteration/R5/R5.0-DECISION.md)，原交付候选及证据包保留历史原文。只收纳当前 AI 页面的整个消息阅读表面，包含消息、执行卡、加载历史与回底部入口；Composer、草稿、附件及原业务错误/确认入口保留。不同于隐藏会话、停止 Run 或关闭 Inspector。

1. 默认展开。唯一显式切换按钮在 AI Canvas 顶栏，文字/可访问名称为“收纳阅读区”或“展开阅读区”，aria-controls 指向保留的阅读容器，aria-expanded 与实际终态同步。收纳后顶栏恢复按钮始终可见、可用 Tab/Enter/Space 操作。收纳区有静态说明；Escape 沿用最高层 dialog/Inspector 语义，不新增全局快捷键。
2. 收纳为组件生命周期内本地状态，不写路由、消息、会话、Run、服务端、localStorage 或草稿 store。所有真实消息、文件卡和 Composer 保持挂载。hidden + inert 从布局、可访问树及焦点序列移除阅读内容；不克隆、不截图业务 DOM、不增加 MutationObserver。
3. Composer 的输入、选择、IME 防护、发送资格、附件与请求幂等完全沿用现有实现。真正通过输入提交 guard 后、发送调用前恢复阅读；失败仍保持阅读并保留原草稿/附件。自动恢复不 focus，不额外发送/重试。
4. 资格按现有 isTerminalRunStatus 判断，只有 succeeded/failed/cancelled 是终态。queued/running/cancelling（含 running 的等待审批）和未来/未知非终态都禁用收纳。未完成加载、加载历史、建会话、发送/确认未知、停止、状态同步失败/降级、权限/账户/会话身份未确认或业务错误也禁用。没有 activeRun 仅在已加载的匹配会话中视为已确认没有活跃执行。审批 unknown 不触发新查询；非终态本身已阻止收纳，终态权威优先于旧 phase/审批展示。
5. 新消息集合引用到达即展开，包括新回复、流式更新、晚回复、历史刷新/加载，不比较动画 phase 或依赖动画完成。已有执行恢复或状态变未知也同步展开，保留正常停止/审批入口。历史刷新即展开是首版保守规则，避免收纳中继续分页或错过事实变化。
6. 手动恢复优先恢复首个可见消息及其 viewport 内偏移；原来在底部则回底部。resize/文字放大后仍按同消息偏移恢复；锚点丢失回退原 scrollTop 并由浏览器限幅。收纳时忽略隐藏 viewport 的 scroll/align，避免零几何破坏原滚动状态。恢复不调用加载接口。自动恢复也保留阅读锚点，原有“有新消息 / 回到底部”入口继续可用。
7. 切会话、切区域、退出/换账户、权限 capabilities 变化使本地收纳状态失效；返回 AI/原会话默认展开。刷新/卸载默认展开，不做每会话收纳缓存。Inspector 打开/返回/关闭沿用原路由/guard；桌面允许阅读区收纳与 Inspector 独立存在。窄屏 modal 自然阻止操作背景顶栏。脏编辑不受收纳影响。
8. 手动切换保留焦点在持久顶栏按钮；若辅助/程序激活时焦点仍在即将隐藏的阅读子树，则移到切换按钮（preventScroll）。自动恢复不抢 Composer/Inspector/dialog 的焦点；原 Surface 返回 hidden 来源时使用其既有安全回退。窄屏、减动、宿主侧栏不可见或 document.hidden 均不依赖视觉运动。hidden 时不接受新的收纳激活，已收纳可安全保留；后台事实到达仍自动展开，恢复后没有补播。

本轮没有粒子、相位、吸纳、材质、覆盖层、动画 controller、新 timer/RAF/observer 或新全局监听器。旧 HpThread 历史对齐 MutationObserver 保留，仅增加隐藏几何保护；不以其补丁实现收纳。

验收与限制见 R5.0-ACCEPTANCE 和本轮 VALIDATION_RESULTS。R1–R4 接受布局/视觉仅增加必要的顶栏收纳控制与收纳占位，不重设计其他界面。后续特效/R6 不在此合同授权内；用户当前仅要求下一步方案。
